# grpcgi.github.io

The [grpcgi](https://github.com/grpcgi/grpcgi) website. Plain static HTML, no
build step: edit `index.html`, push to `main`, and the GitHub Pages workflow
publishes it.

- `index.html` — the site.
- `logo/` — the grpcgi mark, dark and light.
- `.github/workflows/deploy.yml` — uploads the repository root to Pages.
